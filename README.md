#  Flashy

### Arabic → English Flashcard App

A simple desktop flashcard app built with **Python, Tkinter, and Pandas** to practice Arabic vocabulary.

##  Features

- 🇸🇦 Arabic → English flashcards
-  Random word selection
-  3-second countdown
-  Automatic card flip
-  Correct / ❌ Incorrect feedback
-  Live score tracking
-  Saves remaining words to CSV
-  Removes correctly answered words from the learning list


##  How It Works

**1.** An Arabic word appears.

**2.** You have 3 seconds to recall the English meaning.

**3.** The card automatically flips to reveal the answer.

**4.** Choose ✅ if you knew it or ❌ if you didn't.

**5.** Your score and learning list are updated automatically.

## Built With

- Python
- Tkinter
- Pandas
- CSV
